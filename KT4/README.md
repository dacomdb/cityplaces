# Городские места

https://dacomdb.github.io/cityplaces/

Небольшой сайт о Москве, её архитектуре и местах для прогулок. В подборке собраны Крутицкое подворье, Дом Мельникова, Нескучный сад и Чистые пруды.


## Страницы

- `index.html`: описание проекта и несколько мест, с которых можно начать знакомство.
- `places.html`: четыре места с короткими описаниями и расположением.
- `history.html`: истории Дома Мельникова, Крутицкого теремка и названия Чистых прудов.
- `style.css`: общие стили и оформление для небольших экранов.


## Как открыть

Открыть `index.html` в браузере. 
Сайт работает без установки программ, сборки и подключения к интернету. 

Написан на HTML и CSS - все ссылки навигации относительные, на небольших экранах блоки главной страницы располагаются друг под другом.
